# weldblob

Weld encode/decode helpers for blob payloads in pipelines.

**Site:** https://theworker02.github.io/weldblob/

## Install / run

```bash
git clone https://github.com/theworker02/weldblob.git
cd weldblob
node src/cli.js
node --test
```
